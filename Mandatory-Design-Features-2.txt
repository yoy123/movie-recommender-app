User confirmed OpenAI actually WORKED after turning the previous switch on; the old application gate caused the fallback, not a proven invalid API key. Always request AI first for both movies and TV, including existing users whose old stored switch is false. TMDB is used only when an AI request fails, key or safe candidates are unavailable, or output is rejected. Retain the debug fallback alert and a static notice that selections/preferences go to OpenAI. Build and validate on device.

10. In Favorites, add "Select for Recommendations" to each movie/show's card options alongside "Watch Options" and "Delete from Favorites". Support both adding and removing a selection, show its selected state, respect the maximum of five recommendation inputs and movie/TV mode, and ensure Firestick DPAD/OK can reach and activate the action. Selecting an existing favorite as an input does not mean it may be returned as a recommendation; saved favorites must still be excluded from recommendation results.

This is an outstanding design and functionality requirement, not a completed fix.

12. Diagnose and fix TMDB fallback producing exactly the same recommendation list for completely different sets of selected titles.
